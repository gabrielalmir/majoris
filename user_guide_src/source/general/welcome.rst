##################
Welcome to Majoris
##################

Majoris is the drop-in base of CodeIgniter 3 maintained in this
repository. The toolkit is the same CI3 model: libraries for the tasks
a PHP application already expects, loaded through ``index.php`` and
``system/core/CodeIgniter.php``, without a new kernel.

An existing application keeps its ``application/`` directory. New config
keys, when they exist, keep today's behavior.

*******************
Who is Majoris For?
*******************

Majoris is right for you if:

-  You want a framework with a small footprint.
-  You need exceptional performance.
-  You need broad compatibility with standard hosting accounts that run
   a variety of PHP versions and configurations.
-  You want a framework that requires nearly zero configuration.
-  You want a framework that does not require you to use the command
   line.
-  You want a framework that does not require you to adhere to
   restrictive coding rules.
-  You are not interested in large-scale monolithic libraries like PEAR.
-  You do not want to be forced to learn a templating language (although
   a template parser is optionally available if you desire one).
-  You eschew complexity, favoring simple solutions.
-  You need clear, thorough documentation.
