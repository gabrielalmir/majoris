###################
Downloading Majoris
###################

Majoris is this repository. Use the ``main`` branch.

-  `Majoris on GitHub <https://github.com/gabrielalmir/majoris>`_
-  `Archive of main <https://codeload.github.com/gabrielalmir/majoris/zip/refs/heads/main>`_

There is no separate stable tarball yet. Install by replacing the
application ``system/`` directory, or by pointing ``$system_path`` in
``index.php`` at this tree. Keep the existing ``application/``.

Historical CodeIgniter 3 packages remain at
`bcit-ci/CodeIgniter <https://github.com/bcit-ci/CodeIgniter>`_.
Those packages are the upstream project, not Majoris.

******
GitHub
******

`Git <https://git-scm.com/about>`_ is a distributed version control system.

Public Git access is available at `GitHub <https://github.com/gabrielalmir/majoris>`_.
``main`` is the integration branch. It is expected to run on PHP 7.4 through 8.5.
